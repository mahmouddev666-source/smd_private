## 2) الوضع الحالي (Baseline)

- الواجهة مكتملة الشكل تقريبًا، لكن البيانات كلها في `localStorage`.
- لا يوجد خادم ولا قاعدة بيانات ولا مصادقة حقيقية.
- مزامنة ZKTeco محاكاة (`setTimeout`) وتولّد بصمات وهمية مكررة.
- الترخيص/القفل الوهمي قابل للتجاوز.
- محرك المستندات لا يعرض PDF ولا Word/Excel بشكل صحيح، ويحفظ الملفات base64 داخل `localStorage`.
- لا اختبارات، لا CI، لا README، لا Docker.

### 2.2 الحل المعتمد

> **القاعدة الذهبية:** المستند الأصلي هو الخلفية — لا نعيد رسمه، بل نضع طبقة حقول فوقه.

1. رفع المستند إلى الخادم (وليس المتصفح)، وتخزينه في Volume.
2. تحويل Word/Excel إلى PDF عبر **LibreOffice Headless** داخل حاوية الـ API.
3. عرض PDF عبر **pdf.js**، والصور مباشرة، كخلفية للصفحة.
4. طبقة حقول (Overlay) بإحداثيات نسبية `%` مرتبطة بالصفحة.
5. **ربط الحقول** (Bindings) بدل مطابقة النص:
   `employee.name`, `employee.employeeId`, `employee.department`, `employee.currentTitle`, `employee.nationalId`, `employee.hireDate`, `form.date`, `leave.type`, `leave.from`, `leave.to`, `leave.days`, `mission.destination`, `mission.purpose`, `mission.from`, `mission.to`, `mission.allowance`, `custom`.
6. وضعان: **تصميم** (سحب وإفلات الحقول + حفظ القالب) و**تعبئة** (اختيار الموظف + بيانات النموذج → طباعة/PDF).
7. حفظ القيم في قاعدة البيانات (`form_submissions`) لأغراض الأرشفة والتدقيق.
8. الطباعة من المتصفح بتنسيق A4 صحيح (يدعم العربية 100%)، وتوليد PDF على الخادم في مرحلة لاحقة.

## 3) المعمارية المستهدفة

```
جهاز الشركة (Windows + WSL2 + Docker)
└── docker compose
    ├── web        Nginx: React build + proxy /api
    ├── api        FastAPI (Uvicorn) + LibreOffice للتحويل
    ├── worker     مزامنة ZKTeco + نسخ احتياطي مجدول
    ├── connector  pyzk (TCP 4370)
    └── db         PostgreSQL 16 (Volume دائم)
```

**المنافذ:** 80/443 للواجهة — 8000 للـ API (داخلي) — 5432 محلي فقط — 4370 للأجهزة (شبكة محلية).
**الوصول:** `http://smd-hr.local` أو `http://<LAN-IP>`.

## 6) معايير القبول النهائية (Definition of Done)

1. الدخول بكلمة مرور حقيقية، وكل دور يرى ما يخصه فقط.
2. البيانات مركزية على جهاز الشركة وتظهر من أي متصفح على الشبكة.
3. لا سجلات مكررة ولا `NaN`، والإضافي يطابق الحالات المعتمدة.
4. الإجازة لا تُعتمد إلا بصلاحية، ولا تُخصم إلا مرة واحدة، ولا تتجاوز الرصيد.
5. رفع مستند SMD → عرض كما هو → تعبئة ببيانات الموظف/المأمورية → طباعة مطابقة.
6. بصمة حقيقية تظهر مرة واحدة (أو بديل موثق إن تعذر الوصول للأجهزة).
7. نسخة احتياطية تلقائية + استعادة مجرّبة.
8. `docker compose up` يعمل من الصفر في أقل من 15 دقيقة.
9. لا بيانات وهمية تُعرض كحقيقية، ولا ترخيص قابل للتجاوز.
10. UAT موقع + دليل مستخدم + دليل نشر.
